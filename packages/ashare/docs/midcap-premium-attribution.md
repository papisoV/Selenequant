日期：2026-10-02
状态：**收线（止损）** — 自研研究段在此终止，不再向下切分；**收线后补做了一次交叉验证（batch15）**
范围：csi500 等权基线超额收益的来源归因（batch11 → batch15）

## 这条线问的是什么

`packages/ashare` 的复合因子策略在 **csi500 等权**配置下取得 **+30.9%/年、IR 1.66** 的超额
（reb=21 / n_long=20 / equal，batch11 实测），而在 **hs300 池全域为负**。这条线追问：
**csi500 这部分超额从哪来 —— 是配置的产物、某种市况的幸运，还是池结构本身的性质？**

### batch15 的准确读法（重要）

换 regime 源后主证据档 reb5 的规则 1 不再通过，但翻转格很小：

- **翻转发生在 neutral 态**：n=6 窗 / 5 独立段，均值从 +0.24%/窗 到 **−0.15%/窗** —— 是
  原本就贴近 0 的格子发生**小幅符号翻转**，非大幅反转。
- **双向读法**：既**不能**说「结构溢价被推翻」（6 窗小格、幅度在噪声范围），也**不能**说
  「稳健」（预注册判据就是「三态全正」，换源后 FAIL，按定义集冻结纪律这是实质限定）。
- **稳健的部分**：「bear 态超额在所有源下都最肥」（905 +1.33% / 300 +0.98%/窗）。
- **不改写 batch13 封印结论**：其在 000905 定义集下仍成立 —— batch15 限定的是它的**适用范围**
  （限于 000905，不外推），不是推翻它。

### batch14 的准确读法（重要）

D5 判定为 **样本不足**，**不是否证**：

- settled 期（2025-01 起）从未触及 −20% 的 deep 界（最差 −19.06%），且面板 deep 日结束于
  2024-09-23，早于 settled 窗起点 —— 两个集合在本面板不相交。
- 这是**阈值擦边**（0.19 的界就能产生一个 deep 日），**不是**「回撤深度与 bear 溢价无关」。
- 正确表述：**该问题在本数据集上未获检验**。不得读作否证。

## 止损判定与理由

**结论：自研研究段在此收线。** 理由：

1. **认知收益已兑现，边际在递减。** batch12 排除加权解释、batch13 判定结构溢价之后，
   「超额从哪来」这个问题已有可用的答案。batch14 及后续候选问的是「能否再细分」，
   属学术好奇心，非产品需求。
2. **产品侧零增长。** batch12/13/14 三批产出的是研究模块（`regime_windows.py` 至今
   **无 CLI / API 消费者**）与认知，未新增任何端点或页面。能赚钱的配置 batch11 就已定位并落库。
3. **撞的是数据墙，不是方法论问题。** settled 期自 2025-01 起仅 19 个窗（reb21）。
   任何「条件切片」研究都要切进更小的格子；小样本 + 多重比较 = 迟早挖出假阳性。
   换维度切，墙仍在。
4. **候选 2/4 结果可预告。** vol×dd 正式检验切的是更细的格子（deep 档 0 窗），大概率
   重蹈 UNTESTED；hs300 同表已被 batch11/12 证过 18/18 全负。
