# Credit Approval Decision Tree
# Clean-room sample from EXAMPLES.md §1.3.
# Terminals: extreme_risk, high_risk, approve, reject, wait

## 0. 全局原则

本决策树用于信贷审批流程，按数据完整性 → 风险状态 → 决策路径顺序执行。
所有数据缺失或异常情况一律走"否"分支终止为 wait 或 reject。

## 1. 数据完整性闸门

### 1.1 申请人身份信息是否完整
是：进入 §1.2
否：终止 → wait

### 1.2 收入证明材料是否齐全
是：进入 §1.3
否：终止 → reject

### 1.3 征信报告是否在有效期内
是：进入 §2.1
否：终止 → wait

## 2. 风险状态判断

### 2.1 信用评分区间
是[>=750]：进入 §3.1
是[650-749]：进入 §2.2
是[550-649]：进入 §2.3
是[<550]：终止 → extreme_risk

### 2.2 负债收入比是否超阈值
是[<=50%]：进入 §2.3
是[50%-70%]：标记 medium_risk 加权
是[>70%]：终止 → high_risk

### 2.3 行业风险等级
是[稳定行业]：进入 §3.1
是[波动行业]：进入 §3.2
是[衰退行业]：进入 §3.3

## 3. 决策路径

### 3.1 优质客户决策路径
是：进入 §3.1.1
否：终止 → reject

#### 3.1.1 是否存在近期逾期记录
是：终止 → wait
否：终止 → approve

### 3.2 标准客户决策路径
是：进入 §3.2.1
否：终止 → reject

#### 3.2.1 是否存在担保人
是：终止 → approve
否：终止 → wait

### 3.3 高风险客户决策路径
是：进入 §3.3.1
否：进入 §4.1

#### 3.3.1 是否愿意接受提高利率
是：终止 → approve
否：终止 → reject

## 4. 极端风险上报

### 4.1 是否疑似欺诈
是：终止 → extreme_risk
否：终止 → high_risk
